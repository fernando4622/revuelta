# Definition of Done

A feature is complete only when:

- [ ] implementation matches the approved spec;
- [ ] domain rules have tests;
- [ ] application/use-case behavior has relevant tests;
- [ ] persistence constraints/transaction behavior are tested where relevant;
- [ ] API contract is current and verified;
- [ ] authorization is tested server-side;
- [ ] error mapping is deterministic;
- [ ] concurrency implications are tested;
- [ ] no business logic is duplicated across layers;
- [ ] migrations are versioned;
- [ ] observability is adequate for the operation;
- [ ] affected docs/specs/ADR are updated;
- [ ] unrelated cleanup is excluded from the change;
- [ ] verification commands were actually executed;
- [ ] traceability entry is updated.
