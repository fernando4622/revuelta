# ReVuelta Specification Package

This package contains the baseline project governance documents plus the initial product, domain, security, data, API, UI, testing, operations, risk, feature, and ADR specifications for the real ReVuelta application.

## Important

The package deliberately contains explicit blocking decisions where the available project context does not justify a definitive business choice. This is intentional: inventing those choices would violate the project's SDD rules.

## First action in repository

Copy the package contents into the ReVuelta repository root, then review `specs/decision-register.md` with the product/technical stakeholders. Resolve the blocking decisions in the order needed to unlock Phase 1 and the first vertical slice.
